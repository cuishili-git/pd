# 接线图说明

所有图都是白底、中文标注、颜色硬编码（**不依赖界面主题变量**），单独用浏览器打开或打印都不会变黑块。

## 看图顺序

| 顺序 | 文件 | 用途 |
|---|---|---|
| ① | **`雪崩源_完整接线图_100Hz.png`** | **整机接线主图，照着焊**。含 NE555 逐脚、12V 分配、高压充电级、ZTX415、输出、共地，零交叉。另有 [网页版](雪崩源_完整接线图_预览.html) 可无损缩放 |
| ② | `ZTX415_雪崩级接线图_单张版.png` | ZTX415 周边特写，一张图看全 C/B/E 与全部周边元件 |
| ③ | `ZTX415_引脚与接线专图.png` | 脚位详解 + 万用表验脚法 + 参数表，拿不准时再翻 |
| ④ | `雪崩脉冲源接线图_V0终版.png` | 与主图内容一致的备份版本 |

每张图都有同名的 `.svg`（矢量、可编辑）。

## 颜色约定

| 颜色 | 含义 |
|---|---|
| 红 | 200 V 高压区 |
| 橙 | 12 V 低压供电 |
| 紫 | 触发信号 |
| 绿 | 雪崩输出（50 Ω + 天线） |
| 灰 | GND |

**实心圆点 = 相连**；主图做了零交叉设计，所以不需要「交叉无圆点 = 不连」这条老规则。所有接地符号必须**星形汇到 12 V 适配器负极**。

## 数值口径

图里所有高压标注为 **200V 起步 / 250V 封顶**，定时电容为 **100 nF (104) → ≈102 Hz**。早期版本里的 `270V`、`1kHz`、`2N2377` 均已作废，只作为历史文件保留，不要照着接。

## 重新生成 PNG

SVG 改完后，用仓库自带的转图脚本（需要本机有 Edge/Chrome）：

```bash
cd D:/workbuddy/docs/pd
python tools/svg2png.py docs/figures/雪崩源_完整接线图_100Hz.svg docs/figures/雪崩源_完整接线图_100Hz.png 2
# 第三个参数是缩放倍数，2 = 约 2 倍分辨率
```

重新生成可缩放的网页版：

```bash
python tools/make_preview.py
```
