模拟源子项目 V0–V3 方案

完整设计 · 背景

目标：做一个"标准考卷"信号源——在没有任何真实 GIS 的条件下，输出相位可控、模式可复现、幅值可标定的局放模拟信号，用于验收工频同步、PRPD 判型、UHF 射频链路和 APP 显示。 日期：2026-11-04

一、为什么必须有这个子项目

没有模拟源 有模拟源
链路对不对只能等现场 实验桌上就能验收每一级
PRPD 图谱好坏没有对照 四类缺陷图谱有"标准答案"可对
幅值灵敏度无法测量 可复现的脉冲幅度 → 可测最低可检幅值
APP 显示逻辑无法回归测试 固定输入 → 输出永远一致

核心设计思想：一个"模拟源"不是一台仪器，而是四个逐级变难的版本。每一级只服务一类验收，做到哪级用哪级。

三、V0：纯软件仿真（已在固件规划内）

pda-fw 的 SIM_MODE = 1：固件内部按"缺陷模式库"合成每窗峰值，再走真实打包 → USB → APP 全链路。

模式库（四类缺陷的相位指纹，软件和硬件模拟源共用同一份数据）：

缺陷类型 放电相位分布 正负半周对称性 PRPD 目视特征
内部气隙 30°90° 和 210°270° 两簇 对称 "兔子耳朵"双峰
电晕（尖对板） 单半周 90° 附近（或 270°）集中 极不对称 单峰
沿面放电 相位跨度宽（0°~180°） 弱不对称 宽散带
自由颗粒 相位随机、幅值随机漂移 无规律 满屏散点、缓慢移动

验收标准：APP 渲染的仿真图谱与上表描述一致；把模式从"气隙"切到"电晕"，图谱 1 秒内变化。

四、V1：相位定位电脉冲源（工频链路的考卷）

原理

用一块独立的小电路，在指定的工频相位角上发出宽度几十 ns 的电脉冲，注入（或辐射进）被测链路。因为脉冲出现的相位角精确可控，PRPD 上就应该在对应角度出现点簇——这就是"考卷答案"。

市电 220V → 阻容降压 → 光耦过零检测 → 同步方波
                                  ↓
模拟源 MCU（可用另一块 ESP32-C3，¥15）→ 定时器在设定相位角触发
                                  ↓
GPIO 上升沿（~10ns）→ RC 微分 + 比较器整形 → 几十 ns 窄脉冲
                                  ↓
输出：导线耦合 / 直接接到被测板输入

相位模式发生器（软件）

参数 范围 说明
相位角 0~360°，步进 1° 每个脉冲出现的相位
分布模式 单角 / 高斯簇 / 均匀随机 对应电晕/气隙/颗粒
重复率 10 ~ 10000 脉冲/秒 可调
相位抖动 0 ~ ±10° 模拟真实放电分散性
幅值分布 固定 / 对数正态 模拟幅值分散

光耦 PC817 + 电阻电容 市电过零检测 ¥3

⚠️ 安全提示：市电过零检测有 220V 直连部分，必须用光耦隔离，降压电容选 X2 安规电容；不熟悉市电操作就改用"第二块电极板"从空间取过零（零风险，方案与主项目工频同步完全相同）。

验收标准

  1. 模拟源设"单角 90°"→ 主设备 PRPD 在 90°±2° 出现点簇
  2. 设"气隙模式"→ 出现对称双峰，与 V0 仿真图谱形态一致
  3. 相位从 90° 改到 120°，图谱跟着移动 30°±2°（这就是当年板 A 联调的验收项）
  4. 幅值扫描 → 测出主设备最低可检幅值（灵敏度数字的出处）

五、V2：空间辐射 UHF 模拟源（300M–1.5GHz，幅值可调）

需求（2026-11-04 定稿）：空间辐射（不经导线连接，模拟真实局放的电磁辐射路径）、频段 300–1500 MHz（与主设备 UHF 前端完全对齐）、幅度可调整（考板 B 动态范围和衰减补偿逻辑）。

5.1 频谱覆盖的硬指标：脉冲边沿时间

窄脉冲的频谱能量大致平坦地延伸到 f_max ≈ 0.35 / tr（tr = 上升沿）。要覆盖 1.5 GHz：

目标频率上限 所需边沿 tr 对应器件
1.0 GHz ≤ 0.35 ns 雪崩管 2N2377（tr≈0.5ns，勉强）
1.5 GHz ≤ 0.23 ns ZTX415 雪崩管（tr≈0.2–0.3ns） 或雪崩+SRD 整形

结论：原方案 2N2377 只能考到 1 GHz，考不满 300–1500M，换 ZTX415（约 ¥5/只，专门按雪崩工况设计的型号）。 若实测 1.4G 处能量不够，再加一级阶跃恢复二极管（SRD，如 MP4023 类）二次整形，边沿可压到 0.15ns。

5.2 幅度调节：粗调 + 细调两级

手段 范围 精度 说明
充电电压粗调 30–300 V（升压模块电位器） 连续但粗 雪崩脉冲幅值近似正比于充电电压
PE4302 步进衰减细调 0–31.5 dB，0.5 dB 步进 精确已知 DC–4 GHz，ESP32-C3 走 SPI 控制；与主项目 R1 是同一颗器件，买一次两处用
拉距离（兜底） 0.5–3 m 不精确 自由空间损耗 20·lg(d)，只做定性验证

组合起来：电压做量程档（大台阶），PE4302 做精确刻度（每步 0.5dB 且衰减量软件可查），可以精确复现任意幅值——回归测试时"同一设定 → 同一读数"就是靠它保证。

⚠️ 一个必须提前接受的边界：辐射幅值无法绝对标定（天线增益、空间耦合、极化都进系数），所以"幅度可调"是相对量——用主设备自己的读数建立相对刻度即可（这正好也是考衰减补偿逻辑的方式）。绝对 pC 标定仍由 V3 注入法承担，两条通道各司其职。

5.3 天线：从"短导线"升级为可复现宽带天线

短导线辐射方向图和频谱都不可复现，每次摆的角度不同读数就不同，回归测试没法做。替代：

方案 成本 300–1500M 覆盖 说明
PCB 蝶形/平面单极天线（立创打样） ~¥30/5 片 ✅ 平缓 一次打样多片，发射/参考各留几片，首选
市售 UWB 蝶形天线（3.1–10.6G） ¥20–40 ⚠️ 高段好、300–500M 偏弱 应急可用
盘锥天线 ¥50+ ✅ 全段最平 体积大，桌面不便

5.4 整机结构（V1 的相位控制直接复用）

市电过零（光耦）或电极板空间取过零 → ESP32-C3 相位模式发生器
        ↓ 设定相位角触发
雪崩级（ZTX415，充电 30–300V）→ <0.3ns 电流阶跃
        ↓
PE4302 步进衰减（0–31.5dB）→ PCB 蝶形天线 → 空间辐射

V1 的模式发生器固件（单角/高斯簇/随机、重复率、抖动）一行不改，只是把"输出到导线"换成"输出到雪崩级"。

5.6 验收标准

  1. 频段覆盖：主设备频谱扫描在 500 MHz、900 MHz、1.4 GHz 三个频点均能捕获脉冲峰（1.4G 这一点是"覆盖到 1500M"的直接证据）
  2. 幅值细调线性：PE4302 每步进 6 dB，主设备读数下降 6±1 dB（衰减补偿逻辑的考题）
  3. 动态范围：充电电压 30→300V + 衰减 31.5dB 全程，主设备读数单调变化 ≥40 dB
  4. 相位正确性：PRPD 相位簇与设定模式一致（V1 相位控制经辐射通道仍成立——这才是"空间辐射"需求的价值：把天线→前端→超外差→检波→相位整条真实路径全考进去）

六、V3：幅值标定（pC 出处的考卷）

按 IEC 60270 的注入法反推：把模拟源脉冲经一个**已知小电容 Cq（如 1pF、10pF）**注入已知回路，视在电荷 q = Cq × ΔU。

注入电容 阶跃 30V 阶跃 300V
1 pF 30 pC 300 pC
0.1 pF（自制小板） 3 pC 30 pC

验收标准

  1. 注入已知 q，主设备读出的相对幅值与 q 成正比（线性度）
  2. 得到"最低可检测 pC"数字——与商用仪器同条件对比
  3. 换衰减档位后读数经档位补偿后一致（验证衰减补偿逻辑）

⚠️ V3 的绝对精度只能到"数量级正确"（手持机不做严格 IEC 标定腔），它的价值是相对线性和灵敏度下限，不是绝对 pC 值。

四步搭出来：① 升压模块空载先调到 200V（上限 250V，见下方修订），万用表确认；② 洞洞板搭"47kΩ→10nF→ZTX415"，泄放电阻常接；③ NE555（≈100Hz 无稳态，3 脚 OUT → 100pF → 基极节点，10kΩ 下拉）触发雪崩管基极——之后换 ESP32-C3 GPIO 只换信号源一段，雪崩级不动；④ 输出端接一段 10cm 导线当天线。

引脚：ZTX415 是 E-Line（TO-92 兼容），平面（印字面）朝自己、引脚朝下，左 C / 中 B / 右 E（引脚 1/2/3 = C/B/E），与常见 TO-92 的 E-B-C 相反。依据立创 C5245685 引脚图 C1B2E3 与 Diodes datasheet 封装图 C B E；散装货仍建议二极管档复验，见 D:\workbuddy\docs\ZTX415_引脚与接线专图.png。

最简版的验收就一条：主设备频谱扫描在 300M–1.4GHz 段看到脉冲峰，挪动导线位置读数变化。 出了这个波形，说明雪崩级活着，再逐个补相位→细调→好天线→电池；没出波形，问题也只可能在 8 个元件里。

2026-11-09 频率修订：重复率由 ≈1kHz 改为 ≈100Hz，只需把 NE555 定时电容 Ct 换成 100nF(104)，R1/R2 不动 ⇒ f ≈ 102Hz、占空比仍 51.7%。50Hz 档 = 两颗 104 并联(200nF) ⇒ ≈51Hz。降频后 τ=470µs、周期 10ms=21τ，电容能真正充满（1kHz 时只有 2.1τ，T 节点被拉到 ≈136V）；平均功耗 200mW→20mW；验源压降判据由「几十~100V+」改为 ≈1V → ≈10V。详见 雪崩源_上电验收卡_V0.md 开头修订框。

2026-11-09 高压数值修订（重要，覆盖本节及下文所有 270V / 280–290V / 300V 表述）：查到 Zetex 官方应用笔记 AN8（diodes.com/assets/App-Note-Files/zetex/an8.pdf）后确认——V_CBO = 260V 是绝对最大额定值，不是"必须超过才能击穿的工作点"；雪崩靠基极触发点火，AN8 图 6 给出 10nF 电容下起始电压约 120–175V（随基极驱动强弱变化），图 11a 官方单电容脉冲电路标注 +170–260V，拓扑与本方案几乎相同。因此原定 ≈270V 已越线且无必要。统一改为：200V 起步 → 不出脉冲小幅上调 → 250V 封顶；不出脉冲优先加强触发（100pF→470pF、10kΩ→1kΩ），而不是继续加电压。我们的基极驱动（≈1.2mA）远弱于 AN8 测试条件（50–200mA），所以实际点火电压会偏高，这正是"先加强触发"的原因。详见 ZTX415_引脚与接线专图.png 第 ④ 块。

9.3 采购与安全要点

  1. ZTX415 只在立创买（Diodes 原装，现货稳定）；淘宝的"雪崩管 2N2377"多是打磨翻新，边沿时间不保证，考不了 1.5GHz。
  2. PE4302 与主项目 R1 同一颗器件——如果主项目第一批已计划购买，直接多买一颗/一块模块，模拟源侧就不用再下单。
  3. 300V 安全三件套：升压模块输出先接泄放电阻再断电（#10）、所有高压裸点套热缩管（#19）、调试时只用一只手接触电路。雪崩级电容虽小（10nF），300V 惊吓照旧。
  4. 市电过零那条路（#2–4）如果不确定能安全操作，直接放弃，改用第二块电极板空间取过零（覆铜板已在手，零风险，固件不变）——省 ¥11 且更安全，推荐。
